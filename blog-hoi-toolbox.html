HOI: A Python toolbox for high-performance estimation of Higher-Order Interactions from multivariate data

Journal of Open Source Software · 2024 · Read the JOSS paper

HOI is a Python toolbox designed to make higher-order interaction analysis practical for real-world datasets. It streamlines the workflow from data preparation to interpretation, with a focus on scalability and reproducibility.

Key idea: a fast, well-tested toolbox removes the bottleneck for studying synergy and redundancy in multivariate signals.

The package provides efficient estimators, clear APIs, and diagnostic tools for validating results. It supports common neuroscience data types but is general enough for any multivariate time series, from behavior to climate and finance.

By lowering the computational barrier, HOI enables researchers to routinely test whether group-level effects are present and how they relate to behavior or system dynamics.
