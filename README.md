# Personal Research Site (GitHub Pages)

**How to use**

1. Create a GitHub account (if you don't have one).
2. Make a **new repository** named **`YOURUSERNAME.github.io`** (replace with your GitHub username).
3. Download this zip, unzip it, and upload all files into that repository (drag & drop on GitHub).
4. Commit the upload. After ~1 minute, visit `https://YOURUSERNAME.github.io` to see your site.
5. Edit the `.html` files to add your content. The style is in `assets/style.css`.

**Pages included**
- `index.html` — homepage with News.
- `projects.html` — projects grid.
- `collaborators.html` — collaborators grid.
- `publications.html` — publications list.
- `assets/style.css` — styling.
- `assets/script.js` — small helper for "NEW" badges in News.

**Tip:** To add a news item, copy one of the `<article class="news-item">...</article>` blocks in `index.html` and change the date and text.
